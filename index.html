How it works

Companies report generation once a quarter or half-year. Grid operators publish it every day. We connect the two.

  1. Map each fleet

    Which assets each company owns, where, and at what share, from its own reports. Versioned, so every estimate uses the map as it stood that day.

  2. Read the grid

    Generation by zone and production type from grid operators every morning, and in Great Britain each wind farm’s own meter.

  3. Seal the estimate

    Each morning’s vintage is fingerprinted and committed before the company reports. Nothing is rewritten.

The method in full, with the receipts, is on the data page.

What arrives each morning

One vintage a day, built so it can be backtested honestly.

Granularity
Each company, by bidding zone and production type, per day
Frequency
A new vintage every morning
Point in time
